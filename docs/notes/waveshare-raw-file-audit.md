## RTC与读取时序

PCF85063经SDA47/SCL48、地址0x51接入。初始化只读检查，不写固定日期或随意
清OS/STOP。`TIME`使用本机UTC校准并读回；记录新增type4锚点，原有报告的
单调时间和序号不变。锚点不确定度包含秒分辨率与采样耗时，不是UTC准确度担保。

0.1.2有一次重启后未生成锚点，因此没有直接宣称RTC丢时。0.1.3加入启动只读
重试、后续成功读取的锚点触发及只读CLOCK探针。在不先改写时间的探针中，
RTC已与主机相差0秒；再校准、等待及MCU重启后探针相差0–1秒，OS和STOP均未置位。
该重启后的文件504条报告通过CRC，含source1的RTC锚点，证明这个有界试验下
UTC映射确实保留。未验证同时断开USB与电池后的保时。

最初Mac串口打开操作观察到USB_UART_CHIP_RESET。改用保留控制线并关闭HUPCL
的主机读取方式后，本轮安全停录和读回未出现该非预期复位标记。不能把之前的
会话切换不加区分地归为固件自主崩溃，也不能保证任意终端软件都不复位。

## 当前按键和交付状态

- 已刷0.1.3-raw-clock，最后核对为RECORDING，继续往TF记录。
- BOOT/GPIO0短按切页；PWR/GPIO18长按约1秒请求安全关机。

- 按键、电源及RTC代码通过主机故障/日历测试；实际按键按压、电池供电关机/唤醒
  和电池后备保时尚需实物专项验证。电量采样仍未接入，UI保持未知。
