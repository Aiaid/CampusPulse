# 黑客松交付：实时与历史共用时间轴

更新：2026-10-25。本文是交付操作与待验收清单，不是下午实录或真机通过记录。
先用现场 API 看真实数据，再回看同一批已保存的记录；需要讲解完整交互时，主动
切换到模拟演示。当前构建、线上发布和现场硬件验证须分别记录证据。

## 数据来源与时间轴

| 入口 | 数据来源与用途 | 空数据或失败时 |
| --- | --- | --- |
| 现场观察 `?mode=field` | 当前公共 API 的 BLE 聚合窗口与人工停车／候梯记录；同一横向时间轴连接实时与历史 | 显示无数据、过期或服务不可用，不生成补值 |
| 模拟演示 `?mode=demo` | 教学日／周末／雨天合成曲线、人物车辆与合成时段回放 | 保持模拟标记，不写现场观察、设备数据或研究存档 |

顶部只选择“现场观察／模拟演示”两种来源。现场观察的实时端跟随现在，最近
摘要每 30 秒及返回页面时刷新；拖动时间轴游标或点击记录标记后，游标固定在
所选历史时刻，界面按该时刻解释已载入记录。点击“返回实时”恢复当前摘要与
时间跟随。默认最近 1 小时，可切换 15 分钟／1 小时／24 小时。旧链接
`?mode=replay` 仍兼容，打开同一现场时间轴并将游标停在最新保留记录；没有记录
时显示空状态。真实数据没有自动播放、视频流或缩略图。

历史游标的记录解释严格遵循时间边界：传感器窗口覆盖
`[observed_at - duration_ms, observed_at]`，每个节点分别显示，不把相邻窗口
延长到缺口；人工记录仅在 `observed_at <= 游标 < valid_until` 时显示。
卡片保留记录原始时间，不能把游标时刻写成新的观测时间。多节点记录不相加成人数，
时间轴只关联地点和时刻，不还原个体轨迹。当前查询所选地点的载入数据无法解释
某个时刻时，明确显示该时刻暂无已载入记录。

根路径仍尊重管理员保存的 `default_mode`；管理员可选择现场或模拟。显式模式
链接用于交付时固定入口；未指定模式且设置服务不可用时回到现场视图。此次修改
不自动改写生产设置。这里的“实时”是最近一次已上传观察与定时刷新，不是连续
广播流，也不保证校园全覆盖。GIS 底图与灯光示意均不代表实际传感器或照明覆盖。

历史回看当前依赖在线 API 和保留期，不含文件导入、私有 R2 原始广播播放器或
离线实录包。公共 history 只支持最近 1／5／15／60／1440 分钟，不能查询任意
历史日期；每次每类最多 200 条，截断必须提示。例如单节点每 30 秒一个窗口，
约 100 分钟就会填满 200 条；同点多节点更快。即使仍在最近 24 小时内，较早的
下午记录也可能已经排在返回结果之外。采集后应立即核验所需时段是否可见；
缩短查询范围不能找回已排在最新 200 条之外的旧记录。若要指定较早时段、跨日
或脱网展示，先单独实现并验证区间查询／分页或归档回放，不能把当前入口
称作已经可离线保存的录制。

## 出发前

- [ ] 确认本次浏览器实际加载的提交／构建和 API 环境，核对现场／模拟两个来源、
      现场时间轴和旧回放链接的桌面／手机布局；本地构建成功不能代替线上验收。
- [ ] 用实际手机／设备在拟用网络访问站点与 API；确认管理员登录、设备身份、
      当前配置应用和节点状态。保留已存配置，遇到失败先看
      [配网诊断](device-onboarding-diagnostics.md)，不以重新登记掩盖问题。
- [ ] 选定少量可核实地点，记录 `place_id`、GIS 锚点、设备 `node_id`、
      `placement_id`、`capture_config_id` 和起止时间；时间记 ISO UTC，并注明
      本地为 Asia/Shanghai。核实实际摆放位置，地图标记不能代替现场确认。
- [ ] 确认采集策略、保留期和研究原始流是否需要开启；公众演示只需要聚合窗口。
      上传凭据、原始 MAC／AD 和管理员诊断放受限环境，不进入网页展示或源码。
- [ ] 准备手机秒表、供电和操作员凭据；凭据只输入记录表单，不录入截图或日志。
      当前表单接收已完成的候梯秒数，没有自动开始／结束计时或离线补传队列。

## 下午现场采集

- [ ] 固定点先确认设备时间、有效 placement／策略和扫描状态，再开始记时；
      记录开始、结束、移动、断网和其他异常的实际时间。移动设备先切换地点归属；
      不把转场广播当成固定点变化，不给设备补造 GPS。
- [ ] 连续观察一段足以出现多条完整窗口的时间；保存实际上报的窗口数、
      `scan_enabled_ms`、质量标记、丢失、队列压力及 ACK 情况。
      不从一次构建或 USB 连接推定射频、Wi-Fi、持久上传已通过。
- [ ] 在已核实停车点提交真实数量范围；候梯结束后输入实际秒数。
      等待“服务端确认”，再从另一浏览器或刷新后的页面核对；误录先撤销再新建。
      表单当前把首次提交时刻作为 `observed_at`，应及时录入，不用旧值模拟刚完成。
- [ ] 若安全可控，观察一次网络中断与恢复：记下扫描／缓存状态、最后窗口时间、
      重试、ACK 与回收结果。没有做该项就记“未验证”，不要事后补作通过结论。
- [ ] 通过公共 summary／history 核对本次地点与时间对应的聚合记录；
      合格 `field` 窗口才进入公众投影，测试数据和不合格窗口不会因此出现。
      空数据先核对配置、归属、时钟不确定性、保留期和上传，不能改成模拟覆盖。

本地会话笔记或受限导出可放在已忽略的 `captures/` 下。记录会话标识、地点、
实际起止时间、节点／配置、观测数量、异常、所用构建与验证结论；不要在公开
交付文档内附带密钥、原始广播或私人观察。私有备份不代表网页已经支持导入。

## 采集后回放验收

- [ ] 在同一地点时间轴选择包含现场时段的范围，拖动游标并点击记录标记；确认
      游标固定在准确时刻，记录的原始时间、BLE 节点、人工来源和值与 API／现场
      笔记一致，后台刷新不把游标带回当前时间。
- [ ] 检查窗口起止、缺口、人工记录生效／到期边界、质量问题和截断提示；传感器
      仅在窗口覆盖游标时出现，人工记录按当时有效期显示。缺失不延用相邻窗口或
      补零；不同节点分别显示，不求和成人数，不把过去候梯样本称当前预测。
- [ ] 确认历史回看只读取数据；切换时间、地点和来源不重发观察或设备上传。
      撤销的人工记录按当前公共 API 不再返回，回放也不是不可变审计档案。
- [ ] 点击“返回实时”后恢复最新摘要和时间跟随；切到模拟后显示合成来源，场景
      人物和曲线不会出现在现场时间轴的实时／历史状态中。服务失败仍保留错误和
      来源边界，历史数据不能冒充当前可用数据。
- [ ] 桌面和手机各走一遍，记录浏览器、构建、API 环境、实际可用的时间范围和
      已知缺口。若只用 fixtures 验证界面，明确写“合成测试”，不称现场实录验收。

## 建议演示顺序与交付证据

先打开现场链接，选已验证点位，解释 BLE 统计量、观察时间与有效期；再展示一条
真实人工记录及云端确认。接着直接拖动同一时间轴，回看下午同一地点的变化与
缺口，再点击“返回实时”继续观察。
最后主动切到模拟，演示其他地点、场景、时间轴与视觉层，说明它是合成示意。
网络或现场链路失败时，直接说明该项状态，再查看已载入历史或选择模拟来源。

最终交付记录至少包含：源码提交／构建、自动检查结果、实际线上版本、设备与
网络验证、现场会话起止时间、回放可用范围及未完成项。发布流程见
[CI/CD](ci-cd.md)，软件／硬件边界见[架构](architecture.md)与
[固件链路](firmware-chain.md)，未完成工作保留在[路线图](../design/ROADMAP.md)。

## 本地软件验证记录

2026-10-25，统一时间轴修改前的历史快照：601 项测试（53 个文件）与生产构建通过。
`scripts/field-data-browser-smoke.mjs` 以本地 fixtures 验证桌面／390px 手机的
三种入口、独立来源有效期、未定位地点、实测记录选择、截断、空数据和服务失败，
并检查数据卡片不被操作按钮遮挡；`scripts/simulation-browser-smoke.mjs`
验证原有场景切换、双地图、模拟时段与手机布局。两套浏览器检查均无 API 写入、
无页面脚本错误。测试画面使用合成 API／瓦片或在线瓦片，不是下午实录，
统一时间轴修订现已通过 616 项测试（54 个文件）与生产构建。更新后的现场浏览器
检查覆盖拖动到真实采集窗口、游标经刷新保持不变、缺口不沿用相邻值、一键返回
实时、15 分钟／1 小时／24 小时范围切换，以及手机截断提示与操作区互不遮挡。
原有模拟浏览器回归也通过；所有记录仍是本地测试 fixtures，两套浏览器检查均为
零 API 写入、零页面脚本错误，不代表下午现场采集、线上发布或真机验证。

2026-10-25 推送前核验：接上当时最新的 `main` 固件修复后，619 项测试与生产
构建通过。真实本地 Worker 的网页／人工记录浏览器流程，以及时间轴、模拟场景、
GIS 点位的桌面／手机回归均通过。CI 已加入时间轴与模拟场景检查，旧地图检查也
同步到新的地点选择器。这里的提交／撤销只操作本地临时数据，不是生产或真机验收。
